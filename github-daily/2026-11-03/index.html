具身控制：慢脑与快反射的接口

🧩 拆解：REA 把高层推理与低延迟控制拆成异步路由；WorldBridge 连接视频泛化与动作泛化；RoboArchitect 则把机器人外层 harness 的设计也交给自动化。三者不是同一道 benchmark 的竞品，而是分别处理调度、迁移和架构搜索。

💡 思路：模型从「预测下一帧」向「在真实动作时限内作决定」移动。瓶颈既是物理泛化，也是控制链路的延迟与状态持久化；下一步应在硬件闭环中同时计量失败率和响应时间。

🗣️ 见解：优先深读 REA 的运行时边界，再看 WorldBridge 的跨任务证据；不要拿视频演示当机器人可靠性。短期原型会增多，中期真正的门槛是可复现的连续控制评测。 🔗 代表论文：REA: A Routed Embodied Agent Runtime for Asynchronous Brain-Cerebellum Control（HF）；WorldBridge: Bridging Video and Action for Task Generalization in World Action Models（HF）；RoboArchitect: Automating the Design of Robotic Agents with Persistent Memory（HF）。 联动观察：今日 相关榜单/社区入口提示这些研究最终要接受运行环境或用户任务检验，不能只比较论文内指标。

🎯 6. 今日 AI 学习知识点

主推荐：训练—推理分布错配（training–inference mismatch）

是什么：训练器按当前策略求梯度，但生成响应的是另一个实际推理引擎；采样版本、截断、拒绝或数值实现不同，都会让「以为是 on-policy」变成带偏差的更新。见 原论文。为什么是现在：11-01 期刚讨论到「每次推理」核算，今天进一步问「每次推理究竟是不是训练时的那一种」。趋势是把模型、sampler、工具环境与任务规格都纳入同一实验账本。 延伸学习：再读 交互需求的长程编码评测，对照 FreeToken 仓库 的实际 README 和运行约束；动手记录一次真实请求的 model revision、sampling 参数、token 成本与任务验收结果。

🎯 11. C. 阿墨点评

  1. 先给 agent 装刹车，再给它装方向盘。 11-01 期说控制面会变成争夺中心，今天 桌面 CLI和 主动测试 agent把这个判断推得更近了；但权限边界是否落地，榜单没有回答。别让「它会替我点」变成「它会替我闯祸」。
  2. 账单会说谎，尤其分母会说谎。 前期算 token 和机器，今天 训练—推理错配提醒部署分布都可能换了。投资人问单位经济性时，先问「单位是什么、验收是谁做的」。
  3. HN 大事是权重空间编程冲上高位：Astra抓取时 1,983 分。热度证明研究兴趣，不证明可复现；与 10-28「证明作为交付物」呼应，最该公开的是基线、负例与成本。
  4. Web3 的新鲜感不在新缩写。 ethresear 的资产层限额其实在问老问题：谁有权说停。这个问题 agent 也在答，最好别让营销团队来写权限协议。🐍
