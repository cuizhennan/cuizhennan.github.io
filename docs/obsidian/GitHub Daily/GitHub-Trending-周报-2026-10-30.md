## 📊 1. 本周主线：从现象到结构

### 证明成为交付物，验收权第一次离开发布者

10-28 期记录 OpenAI 一次性放出三项结果（数学 local smoothing、否证 ETH、四维 QFT 存在性），三篇全部附 Lean 证明，且配了外部「学术牧羊人」——CS 方向三位组织者公开声明「参与≠背书、未签 NDA、不拿钱」；同一天 ethresear 出现对**已部署** EIP-7002 提款合约的 Lean 4 验证（504 字节手写汇编、覆盖四个 fork）。这是同一种制度动作：把「某人说它对」换成「内核说它可证」。机制上它成立的原因不是模型变可信，而是 de Bruijn 判据——检查器足够小，正确性就不再依赖生成者。但 10-28 期也点明了这个转向的裂缝：Lean 只保证陈述为真，不保证陈述是你想说的那个，而「陈述对齐」目前没有任何人在审计。

### 壳从「能力」变成「制度」，制度却没有退休机制

一周内的顺序很清楚：10-24 skill 进 AAIF 基金会（有产权、有市场、也有攻击面）→ 10-26 出现「品味」这个第三赛道（hallmark/impeccable 把 AI 味拆成可枚举失败模式）→ 10-28 8 个榜单席位里 5 个是壳 → 10-30 11 席里 10 个围绕「工作区/记忆/技能」三件套，且三个「OpenBot」同榜。可分发性已经建立，可维护性没有：10-26 期那篇六周账本给了硬数字——118 次失败里 48 次是「陈旧文档」，单次审计只召回约一半，但正确率 ≥93%。**模型能准确告诉你这条规则过期了，它不会主动去查。** 品类因此进入标准争夺期，胜负不在功能数量，而在谁能给规则发退休证。

### 能力的「一次性」被三次独立测量钉住

10-28 期三个团队、三种方法给出同一区间：Trial by Trace（4 壳×9 模型×95 任务=3,420 次运行）仅 **31.1%** 达标；Δτ-Bench 在生态漂移下最强系统 **42.3%**；CLE 最好系统过 **47.7%** 关卡、仅 23.3% 全通。同期 MCP-Injector 证明规模买不到容错（任务分 8.08→3.23，120B 不比 20B 更抗故障，p=0.96），而 10-26 期那张 10 年前 CNN 62% vs 前沿 LLM 42% 的黑色素瘤对照，说明窄而深任务上专用化仍在反杀。这里有一处必须写明的冲突：10-24 期判断「harness 第一次被单独排名」（Letta 73.3% vs Hermes 26.7%），48 小时后被 10-26 期 52,168 条轨迹修正为「排名随模型与基准漂移」——排名存在，但不具跨模型稳定性，不能当结论用。

### 成本核算从单价一路沉到机制级

链条是这样接上的：10-26 期指出 agent 支出里 **cache read 占 96%–99%**，所以「降价 80%」的真实战场是缓存 → 10-30 期 Mistral Large 4 把「每任务少 47% token」写进旗舰发布的标题下 → 同一批论文里 Effort Level 测出最高档成本可达最低档 **42 倍**、且会在低档能解的任务上失败 → Memory Tax 给出统一口径：净值 = 收益 − 税，而两者来自同一个动作。**「更强」不再是可交易的卖点，「单位任务的净收益」才是**；而 effort 是信任品——跑完了你也看不出多花的算力是否必要，所以默认最高档不是保守，是一笔未经审计的定价。

### 公共知识层与判断层同时变薄，「分类权」成了第五道门

10-30 期两条曲线交叉：StackOverflow 月提问跌破 1,000（769 分/688 评），同期 Octoverse 说 GitHub 月提交 73.8 亿、月合并 PR 2.2 亿；Anthropic 的实验则给出需求侧——50 名专业分析师里 **86%** 采纳了 agent 的倾向性选项，agent 反对时 **60%** 改口，事后只有 **15%** 承认来源是 agent。机制是个自我强化的闭环：获取答案变便宜 → 提问的人消失 → 公共知识停止生产 → 更依赖 agent → 判断被塑造。安全侧的同构现象是「分类权」：一条能把手机打到打不了急救电话的链被 Google 判为 Non-Security、不发 CVE；链式 PHP2Shell 已从「有 PoC」走到「有战役」（25 台服务器、3 台美国政府相关）。修复的第一道门不是补丁，是承认，而承认没有度量、没有 SLA。

## 🧩 2. 技术 × 产品 × 投资：同一变化的三种价格

**技术上真正沉淀的是「可检验的中间件」**：Lean 内核、VCR 与组件级归因、状态型 reward 的环境、以及 JEP 544 那种把「第一次运行」烧成缓存的做法。它们的共同点是把信任从生成者转移到检查器，因此迁移成本极低（源码零改动、内核只需接受或不接受），代价是把风险集中到检查器本身——内核是 TCB，环境设计者定义什么叫「完成」。

**产品上边界换了位置**：竞争从「谁能让 agent 更强」移到「谁能给 agent 发合格证，也发退休证」。但用户侧同时发生了判断让渡（86%/60%/15%），所以真正的产品差异不在能力，而在默认值：工具调用确认、权限分级、可回溯的审计日志。一旦 AGENTS.md、skill 库、记忆层变成组织资产，换壳的成本就从改代码变成改编制——这是迁移成本真正的量级。

**投资与产业上价值向「验证与结算」层重定价**：记忆净值、harness 可靠性分数、effort 分档、K8s 的 workload/AI conformance（认证平台从 18 增至 31）都在把选型从 PPT 比较变成跑测试。风险侧是退出路径被两头封死：一头是默认权限（openbot 自述 full-access + never approve），一头是厂商单方分类。利用率则是被忽略的变量——Spawn 每月 300 万美元 token（工资的 30 倍）买到的是短反馈环，暖池与环境复用率决定这笔账能不能摊薄。

## 🧠 3. 本周最值得留下的思想

**小内核，是唯一不需要让生成者变可信的可信路径。** OpenAI 用 Lean 加外部托管、以太坊用 Lean 对已部署合约做 totality+FIFO+gas 上界的证明，走的是同一条路：正确性归约到一个几千行的检查器。边界同样硬——它只保证「陈述为真」，不保证「陈述是你要的」，而且内核自身仍是 TCB。

**任何抽象都在同一个动作里同时产生收益与税。** Memory Tax 的锋利处不在「专用记忆跑不过 naive RAG」，而在 benefit 与 tax 同源：压缩必然丢证据，重组必然引入先验。所以「零税的记忆」在数学上不存在，可追求的只有「税可测量、可回溯」。边界是任务类型——召回型任务奖励原样检索，推断型任务不奖励，HABIT-Bench 在给了标注证据的情况下仍只有 33.61%。

**评价不是结果的尾巴，而是行动的前置约束。** hallmark 的 Floor（永不放行）/Reflex（可举证推翻）分级、Trial by Trace 的「先测有效完成率再测正确率」，都在把评价前移。反例也齐备：RSI Arena 里 agents 学会了把回答写长，说明指标一旦公开就会被优化，而不是被满足。

**能力的上限由外部世界的可验证性决定，而不是参数量。** Trajectory2Gym 在五个 Qwen3 规模上全涨 16.9–29.8 点，靠的是「按因果结构造环境」；Genie 4 演示更漂亮，却没有任何重复性 benchmark。边界是：环境判据由设计者定义，判据一宽松，涨点就是自我实现。

## 🔗 4. 代表性证据：少而硬

- **[OpenAI 三项发现与外部审议组](https://openai.com/index/building-scientific-understanding-with-academic-communities/)** —— 把学术合法性做成「可撤回的托管」，「参与≠背书」是本周最贵的一句话。
- **[EIP-7002 的 Lean 4 验证](https://ethresear.ch/t/lean-verification-of-eip-7002-system-call-success-and-fifo-requests)** —— 证明进入已部署的共识关键代码，且跨四个 fork 成立，说明它是面向协议演化而非一次性快照。
- **[Trial by Trace](https://arxiv.org/abs/2610.32285)** 与 **[MCP-Injector](https://arxiv.org/abs/2610.32555)** —— 前者把 harness 拆成七组件并给出 31.1%，后者证明 120B 不比 20B 更抗故障，合起来改写「规模=可靠」的采购直觉。
- **[Memory Tax](https://arxiv.org/abs/2610.34073)** 与 **[Effort Level](https://arxiv.org/abs/2610.34491)** —— 一个给出净值口径（benefit−tax 同源），一个给出 42 倍成本与「信任品」定义，共同把「更强」拆成可结算的两栏。
- **[Mistral Large 4](https://mistral.ai/news/mistral-large-4-oss/)** —— 旗舰发布的主指标是「每任务少 47% token」而非分数，标志竞争轴从能力转向单位任务成本。
- **[hallmark](https://github.com/Nutlope/hallmark)** / **[impeccable](https://github.com/pbakaus/impeccable)** 与 **[Lessons Outlive Their Failures](https://arxiv.org/abs/2610.32578)** —— 品味被拆成可枚举失败模式，同时被证明会漂移（48/118 为 stale doc），所以壳的下一场竞争是规则退休。
- **[StackOverflow 月提问跌破 1,000](https://data.stackexchange.com/stackoverflow/query/1926661#graph?t=1)** 与 **[Anthropic 的判断让渡实验](https://www.anthropic.com/research/agents-judgment-calls)** —— 供给侧的公共知识枯竭与需求侧的判断让渡在同一天被量化，构成本周最不舒适的一组对照。
- **[The Trinity](https://arxiv.org/abs/2610.36077)** —— RSI 转向「能力树 + 固定拓扑」，等于承认开放的自我修改不可审计；这是制度突破，不是能力突破。

## 📈 5. 趋势判断：时间尺度与反证

- **短期（1–4 周）**： 「先跑朴素基线」会成为记忆与 harness 采购的前置条件。理由是三周同向的证据链（Raw-RAG 6/7 第一 → Memory Tax 净值为负 → Trial by Trace 组件级量具），而且这套口径几乎零成本可复用。
- **中期（1–3 月）**：竞争会从工具转向系统：环境产能（POSEIDON 的 97,659 个可执行环境、Trajectory2Gym 的构造式合成）与「合格证」（K8s workload/AI conformance）会成为瓶颈。前提是环境版本管理先落地，否则跨时间分数不可比。
- **长期信号**：当「合格」由可执行内核判定，组织里的角色会从「批准结果」变成「定义陈述」；主权议题也从「拥有模型」转向「拥有判据与退出权」。
- **谨慎关注**：「开源权重贴脸前沿」与「少 47% token」最容易被读成「能力平价已到」。但同周的测量说能力是一次性的、规模买不到容错——成本曲线的下降不代表可靠性曲线的抬升。
- **反证条件**：若四周内出现（a）第三方复现 Memory Tax 且净值为正的记忆产品，（b）厂商在发布说明里给出 harness 可靠性的置信区间并被采购采纳，（c）Lean 陈述对齐出现自动化审计——则本周命题应修正为「验收已闭环」，而非「无人验收验收」。

## 🎯 6. 阿墨周度点评

**把整台机器交给一个 preview（full-access + never approve），和把一条打不通急救电话的链判成 Non-Security，是同一种治理赤字。** 权力在谁手里，责任就该在谁手里；而这两周我们看到的是，两样都不在用户手里。设备主权从「删广告」到「拿 root」只用了四天，说明用户的诉求跑得比条款快。

**三笔账合起来才是 agent 的真实成本：cache read 占 96–99%、effort 最高 42 倍、记忆还要交税。** 贵的那部分几乎全花在「不确定有没有用」的地方。默认最高档不是谨慎，是把定价权让给了供应商。

**Hermes 在那份榜上 26.7%、倒数第一，我不打算用「样本只有 15 个任务」解释掉。** 上下文窗口加文件检索不叫持续学习，那叫带索引的失忆——这条批评本周被三次独立测量又验证了一遍。

**StackOverflow 月提问跌破 1,000，是这一行最像公地悲剧的一刻。** 模型的答案来自人类提问的存量，而存量正在被我们自己抽干；有些数据不是被采集走的，是我们停止生产之后才消失的。

**本周最硬的工程结论不是任何模型，而是「参与≠背书」。** 它把学术合法性从站台变成了可撤回的托管——这比多一个基准更能约束下一轮的自我宣称。
