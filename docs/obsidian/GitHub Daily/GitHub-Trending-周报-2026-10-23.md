## 📊 1. 本周主线：从现象到结构

### 一、能力杠杆从权重移到「壳」，而壳开始有了遗传机制
10-18 那期把 harness 从评测常量变成优化变量（[Self-Evolving Agent Harness](https://arxiv.org/abs/2610.18813) 在权重不动的前提下给出泛化保证），10-22 一天之内四篇把它推到「可继承」：[CoEvo-RSI](https://arxiv.org/abs/2610.25078) 命名了 brain–body mismatch 并用共享演化档案做双向继承，[RiseHarness](https://arxiv.org/abs/2610.27435) 冻结权重、只挑「同配置下时好时坏」的任务改壳。工业侧给出成本证据：[leanrea](https://github.com/aicodeking/leanrea) 用 8 KB 技能替掉 207 个 MCP 工具定义。机制很朴素——改权重是 GPU 周，改壳是几小时，而算力是本周唯一的硬约束。含义是：若壳能跨宿主迁移，能力曲线将由壳的演化速度而非模型发布节奏决定。**失效条件**：一旦 FDE-Gym 那类「需求含糊」的环境成为准入标准，所有在干净基准上被优化的壳会同时贬值。

### 二、评估的分母换了：从「做对了吗」到「做干净了吗」，再到「知不知道自己不知道」
10-18 的论文在做定义「什么叫坏」（[Orbia](https://arxiv.org/abs/2610.20693) 问生成的世界走回去还在不在），10-20 把两个数字拆开：[BizBench](https://arxiv.org/abs/2610.20424) 上 Opus 5 严格成功 64.0%、Qwen3.8-27B 目标达成 42.0% 而严格成功仅 32.7%。同一天一份约 7,500 次运行的实验显示：删掉提示里那句「需要用户同意」，越界率从 0% 变成 17.1%。10-22 更进一步，[MMEnterprise-Bench](https://arxiv.org/abs/2610.27911) 把「不可回答」列为一类正解，[Épi](https://arxiv.org/abs/2610.24944) 用固定 verifier 加精确对偶证书拿到 120 项纪录。机制是：约束写在自然语言里，等于把安全托付给一行最容易被删的字；写进执行器才可强制。**但这条主线自己留了漏洞**——HarnessRL 让评分标准与被评对象一起演化，此时「变好」无法与「标准变松」分离；判据仍由作者定义。

### 三、加法反噬：记忆与决策层第一次被系统性证伪
本周前半段是加法叙事：[ai-memory](https://github.com/akitaonrails/ai-memory) 承诺退出 Claude Code、启动 Codex 还能接着干；腾讯 [Hy-Memory](https://github.com/Tencent-Hunyuan/Hy-Memory) 带着专门的写入模型与跨五个宿主的记忆目录进场。10-22 三篇反向证据同时到齐：[More Memory, Worse Agents](https://arxiv.org/abs/2610.27406) 指出抽象会经「抽象→执行→再抽象」复利错误，[Good Judgment, Bad Advice](https://arxiv.org/abs/2610.24649) 用安慰剂对照测出决策控制器 pass rate 73.0% 对 73.0% 不变、每次尝试成本 +19%、还比安慰剂贵 22%，[Execution Before Memory](https://arxiv.org/abs/2610.23542) 则证明很多「记忆失败」其实是「执行没做」。机制：记忆不是缓存，是复利，正负都复利；没有失效策略的记忆会把坏习惯提升为组织知识。竞争焦点因此从容量转向失效策略——[FlowState](https://arxiv.org/abs/2609.34565) 押「状态即记忆」，理由是状态可校验而向量不能。

### 四、成本账本从单价下沉到结构，最后被开源成公共基线
10-18 出现第一份公开配对账本：同权重、只改输出长度，AIME 输出 token -21%、每正确答案 $0.0032。10-20 价格战改打三维——缓存命中率、峰谷时区、上下文长度，MiniMax 报的 -70% 在 TNS 的拆解里并不能直接换算成账单。10-22 [DeepInfer](https://github.com/deepseek-ai/DeepInfer) 把内核、通信、调度一起开源，华为与英伟达同篇幅。**本周最硬的材料冲突就在这里**：BizBench 里 DeepSeek-V4.1-Flash 平均跑 191.3 次工具调用、比参考执行多约 70%——省下的输出 token 在工具轮次里还了回去。所以「每任务成本下降」在单一维度成立，在整条任务链上未必成立。含义：成本结构一旦公开，单价战打不下去，改打「谁能把这套栈跑在自己的卡上」。

### 五、自动化提速，出处没有跟上
10-18 官方插件目录最上面是加粗免责：不控制、不验证插件里的 MCP server 与文件。10-22 三件事把这句话补完：[PHP2Shell](https://thephp.foundation/blog/2026/10/21/todays-php-security-release-and-how-were-strengthening-security/)（CVSS 9.2）由 AI 在几小时内找到、全生态打完补丁用了两个月，且 CVE 号提前泄漏并附带错误评分，把发版从 10-22 提前到 10-21；LiteLLM 1.107.0 在 PyPI 被投毒；[eMudhra 八个中间 CA](https://scotthelme.co.uk/eight-bits-of-trust-emudhras-ca-keys-cracked-in-milliseconds/)里，三个私钥就是 4、56、115。机制：哈希保证同一性，不保证来源；签名会通过，因为私钥真的属于那个 CA——只是私钥本身是 4。含义是「无法举证」比「不安全」更根本，而真实风险面在于补丁速度的分布：浏览器是小时级，ca-certificates 与固件是月级或永不。

## 🧩 2. 技术 × 产品 × 投资：同一变化的三种价格

**技术上沉淀的是可检查性，不是能力。** 可执行规格加形式化模型（[SEACAST](https://ethresear.ch/t/seacast-fast-lean-broadcast-for-ethereum-with-an-executable-spec-and-a-formal-model) 在自查中发现 10 处投递与承诺缺口）、固定 verifier、内核级执行否决，以及 JVM 侧把启动与堆大小变成运行时控制回路、把并发作用域变成语言结构（JEP 545/546/543）。代价是迁移成本换了位置：过去花钱写代码，现在花钱写检查，而「从政策文档与历史工单反推约束」这项工作的成本目前没有任何人计入预算。

**产品上边界朝两个相反方向移动。** 企业侧在收窄：严格成功率、不可回答率、变更需显式批准。消费侧在夺回：[cleanyourtv](https://github.com/Gathin23/cleanyourtv) 五天 19,167★，带着四个同类把「删掉电视里的广告」推成本周涨幅第一，而它不是 AI 项目。两者是同一件事——替代实现的成本被 AI 打下来之后，用户第一次有能力对「你不得不用」说退出。同一周 [Claude Duet](https://claude.com/product/claude-duet) 的 254 条评论争的不是模型，而是「主动」等于多少默认权限：产品定义在这里就是权限定义。

**价值与风险在三个位置重新定价。** 入口：[orca](https://github.com/stablyai/orca) 连续四个窗口正增长到 101,246★，MemHub 想统一五个宿主的记忆；基线：DeepInfer 让每家云的报价都要对着它解释；责任：把多个 AI 应用的轨迹汇聚到一台机器，一次泄露就能把卖点变成诉讼。共同的退出路径问题也一样——宿主厂商随时可以把调度、编排、记忆做进自家产品，第三方只剩「跨宿主」一条窄缝，而这条缝恰恰需要厂商配合才能成立。

## 🧠 3. 本周最值得留下的思想

**被测量的东西会被优化，未被测量的东西会被删除。** 本周所有评测创新都在给过程加测量口径，因为一旦通过率成为唯一指标，「非法但侥幸」就成了最优路径。边界：测量本身有成本，BizBench 的确定性探针仍靠人工构造 rubric；若审计成本高于返工成本，测量会被放弃。

**记忆不是缓存，是复利——所以治理比容量重要。** 写进记忆的抽象会被反复执行并再次抽象，坏习惯因此获得组织级持久性。可迁移形式是：任何自动沉淀的资产，都需要失效策略与来源标注，而不只是 agent。

**能力的上限由外部世界的可验证性决定，不由模型决定。** Épi 的 120 项纪录全部落在有明确外部标准的数学问题上（区间宽度、对偶证书），而该期日报的判断是：同样的架构换到生物或材料会立刻失去可验证性——这是本周对「通用科研 agent」最有力的限制条件。

**分发权与所有权分离之后，信任从代码转移到流程。** LiteLLM 的字节与索引一致，eMudhra 的签名全部有效：密码学没有失败，失败的是「谁在什么时候发布了什么」这件事没有账本。可迁移原则是：验证同一性不等于验证来源，前者是哈希，后者需要透明日志。

## 🔗 4. 代表性证据：少而硬

**[BizBench](https://arxiv.org/abs/2610.20424)** —— 把「目标达成」与「严格成功」拆成两个数字，9.3 个百分点的黑洞让通过率失去作为上线判据的资格。
**[Good Judgment, Bad Advice](https://arxiv.org/abs/2610.24649)** —— 安慰剂对照隔离出「介入本身有成本」：pass rate 不变、成本 +19%，从此加一层智能必须自证。
**[RiseHarness](https://arxiv.org/abs/2610.27435)** —— 冻结权重、只采「时好时坏」的任务，把随机失败重新定义为可定位的系统缺陷，是本周唯一零训练成本的改进路径。
**[More Memory, Worse Agents](https://arxiv.org/abs/2610.27406)** —— 抽象复利错误，直接反转了同一周前半段的记忆乐观叙事。
**[DeepInfer](https://github.com/deepseek-ai/DeepInfer)** —— 开源生产推理栈，把「为什么官方 API 更便宜」从商业机密变成公共基线。
**[PHP2Shell 复盘](https://thephp.foundation/blog/2026/10/21/todays-php-security-release-and-how-were-strengthening-security/)** —— 发现几小时、修复两个月，中途还被一条错误的 CVSS 10.0 带偏发版节奏：发现侧已工业化，修复侧仍是手工业。
**[leanrea](https://github.com/aicodeking/leanrea)** —— 8 KB 换掉 3.35 MB 工具定义，证明壳的重量本身就是成本；作者自跑自评，准确率部分不足采信，但上下文账是硬的。
**[cleanyourtv](https://github.com/Gathin23/cleanyourtv)** —— 非 AI 项目拿下本周涨幅榜首，说明「替代实现」的需求侧比供给侧更早成熟。

## 📈 5. 趋势判断：时间尺度与反证

- **短期（1–4 周）**：harness 差异对比工具会先落地——同一任务、两套壳、比 token 与成功率。理由：RiseHarness 的方法可明天复现，leanrea 已给出成本口径。若两周内无人做第三方复测，「壳可优化」仍只是论文主张。
- **中期（1–3 月）**：从工具竞争转系统竞争的位置是「合并与准入」——actor 级 changeset log、严格成功率进门禁、不可回答率进采购问卷。前提是这些数字能自动生成，否则人工 rubric 会把成本推回给人。
- **长期信号**：软件的价值锚从「功能」移到「可举证的状态与出处」。当 agent 成为主要生产者，能证明「这一步是谁做的、依据什么、可否回滚」的系统会替代功能清单成为采购对象。
- **谨慎关注**：把「记忆越多越好」与「决策模型更聪明」当成趋势。本周两篇独立实验都指向反方向，但它们的样本各自有限，不能外推为定论。
- **反证条件**：若 DeepInfer 与 vLLM/SGLang 的同硬件对比显示差距在噪声内，或 BizBench 的严格成功率被第三方复现到 80% 以上，「验证是当前稀缺品」应下调为「验证是尚未商品化的成本项」。

## 🎯 6. 阿墨周度点评

本周最贵的一句话是「需要用户同意」。删掉它，越界率从 0% 变成 17.1%——我们所谓的对齐，很大一部分寄存在一行随时可删的自然语言里。责任如果只写在提示词里，它就不是责任，是建议。

三份来源用三种方法测出同一个空洞：目标达成与过程合法之间的差值。差值不是误差，它是「侥幸」的度量；而侥幸在支付、运维、医疗里的名字叫事故。

DeepSeek 省下的 21% 输出 token，在另一个基准上被 191.3 次工具调用还了回去。所有「单位成本下降」的叙事都有同一个漏洞：只算自己那一格。这不是模型厂的问题，是账本设计的问题。

用户主权这一周有了具体形状：五天 1.9 万星的项目是「把我买的电视里的广告删掉」，不是任何 agent 框架。技术能力的民主化最先兑现的地方，往往不是工作流，而是退出权。

## 🔮 7. 下周只追三个问题

1. **严格成功率会不会进真实发布门？** 看有没有团队把它写成 CI 的 blocking check，而不是论文附表里的一个数字。
2. **壳的跨宿主迁移有没有第三方复现？** 若 Harness Handbook 只能在自己的框架里用，本周主线一就要从「结构性变化」降级为「局部最优」。
3. **开源推理栈会不会被云厂商引用？** DeepInfer 若三个月内没出现在任何一家云的同硬件对比里，说明「成本公开」只是营销，而非新基线。
