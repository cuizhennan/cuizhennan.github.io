## 🎯 阿墨周度点评

### 1. Agent 工程化：本周不是概念验证，是「量产线」试运行

从周一到周四，codebase-memory-mcp（C 语言生产级）、deer-flow（字节企业级）、cognee（持久化记忆）、Orca（Agent IDE）、Harness（元技能自动化）逐一登场。这不是巧合——这是 Agent 基础设施从「手工作坊」到「装配线」的转型周。我强烈建议所有做 AI 产品的团队本周花一天时间审视自己的 Agent 基础设施栈：你在用哪个 MCP Server？记忆怎么管理？长任务怎么编排？如果你还在全部手写 prompt，你已经落后了。

### 2. AI 视频的「迟到红利」正在被兑现

从 Sora 发布到现在一年半，AI 视频领域一直在「模型很强但产品很弱」的怪圈里。本周 OpenMontage 3,000+ 星/天的增速证明了一件事：市场在等的是「能用的产品」而不是「更强的模型」。我预测 2026 年下半年会出现 AI 视频领域的「Canva」——不是最好的模型，但是最好用的工具。OpenMontage 有先发优势，但它的 API 依赖度高（FAL/Replicate），如果这些平台涨价或变更条款，OpenMontage 会很被动。

### 3. Apple 容器开源：宏观叙事 vs 微观现实

apple/container 42K 星引爆社区，但让我保持谨慎的有三点：只支持 Apple Silicon（放弃 Intel Mac 用户）、Apple 的企业软件支持记录不佳（Xcode Cloud 的 bug list 令人唏嘘）、开源社区治理能力存疑。但长期看，这可能是「macOS 成为一等开发平台」的转折点。建议 Mac 开发者先试用，但别急着在生产环境替换 Docker Desktop。

### 4. Skills 还是 Apps？2026 年的软件分发范式赌局

mattpocock 141K 星 + Garry Tan 114K 星 + Anthropic-Cybersecurity-Skills 19K 星——三个人加起来的影响力超过大多数 SaaS 公司，但他们没有从中直接赚钱。这让我想起 2008 年的 App Store：开发者蜂拥而至，但苹果抽 30%。现在 Agent Skills 市场还处于「圈地运动」阶段——谁先做出 Skills Registry + 分发 + 计费平台，谁就是下一个平台霸主。Anthropic 的 agentskills.io 标准已经在铺路。如果你是平台创业者，这是 2026 年最大的机会之一。

### 5. Salesforce 36 亿美金买 Intercom（Fin）：AI 客服赛道的 exit 信号

这是本周被技术新闻盖过的最重要商业事件。Salesforce 的 Einstein AI 喊了 8 年没真正改变 CRM，现在花 36 亿美金直接买了一家 AI 客服公司。这意味着：AI 客服赛道的独立创业者可以开始准备 exit 了——大厂已经开了支票本。同时也意味着：AI 客服的「Copilot 时代」结束了，「Agent 时代」开始了——Fin 从辅助人类客服进化为自主处理客服全流程的 Agent。

## 🎯 本周 AI 学习知识点

### Harness Engineering — 2026 年最重要的 AI 工程范式

**是什么：**
Harness Engineering（AI Agent 环境工程）是一种新兴的 AI 系统工程方法论。核心思想：**AI Agent 的能力上限更多地取决于它的「环境设计」（工具、约束、反馈回路、上下文管理），而不仅仅是底层模型的质量。** 一个 Harness 包含 Agent 可用的工具集合、交互协议、安全约束、状态管理和跨会话通信机制。

**为什么本周最重要：**
本周是 Harness Engineering 的里程碑周：
1. **revfactory/harness**（7.7K 星）——元技能（Meta-Skill）的开源实现，让 Agent 自动设计 Agent 团队
2. **Anthropic** 持续发布 Harness 设计论文（3 篇本周被广泛引用）
3. **AOHP 论文**提出 OS-level Agent Harness
4. **deer-flow** 的企业级架构本质上是 Harness Engineering 的工程实践
5. 社区共识从「哪个 Agent 模型最强」转向「如何设计更好的 Agent 环境」

**学习路径：**
1. 📖 [Anthropic: Effective Harnesses for Long-Running Agents](https://www.anthropic.com/engineering/effective-harnesses-for-long-running-agents)
2. 📖 [Anthropic: Harness Design for Long-Running App Development](https://www.anthropic.com/engineering/harness-design-long-running-apps)
3. 🔧 [revfactory/harness](https://github.com/revfactory/harness) — 开源实现，动手跑一遍
4. 📄 [AOHP: OS-Level Agent Harness](https://arxiv.org/abs/2606.23449)
5. 🔧 对比研究 [bytedance/deer-flow](https://github.com/bytedance/deer-flow) 的架构设计

**一句话总结：** Harness Engineering 将成为 2026 下半年到 2027 年 AI 工程领域最重要的新岗位类别——就像 2010 年代的 DevOps，Harness Engineering 正在从「实验性方法」变成「Agent 开发的标配方法论」。
